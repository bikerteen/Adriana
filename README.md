# For Adriana

A farewell gift page. Adriana scans the NFC sticker on her National Art Pass, lands here, taps to open, and gets a 3‑2‑1 hyperspace countdown, a confetti explosion, and the pass flying in.

Built with Next.js, [Motion](https://motion.dev) and [canvas-confetti](https://github.com/catdad/canvas-confetti). Animations are inspired by [React Bits](https://reactbits.dev) (decrypted text, split text, tilted card).

```bash
npm install
npm run dev
```

Point the NFC sticker at the deployed URL.
